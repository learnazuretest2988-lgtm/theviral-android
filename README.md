# TheViral.me for Android

Download the latest app: **[TheViral.apk](https://github.com/learnazuretest2988-lgtm/theviral-android/releases/latest/download/TheViral.apk)**

## Install
1. Open the link above on your Android phone.
2. When asked, allow your browser to install unknown apps.
3. Open the downloaded file and tap **Install**.

Sign in with your theviral.me account, or create one in the app.

This repository only hosts app releases. Website: https://www.theviral.me
